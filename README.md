# 🚗 Traffic Dodge

### Dodge the Traffic. Survive the Road. Beat Your High Score!

**Traffic Dodge** is a 2D arcade traffic-dodging game developed using **Godot Engine 4** and **GDScript**.

Take control of your car, avoid incoming vehicles, earn points, and survive as the traffic gets faster!

---

## 🎮 About the Game

Traffic Dodge challenges players to navigate through incoming traffic while staying within the road.

Avoid enemy vehicles, protect your lives, and achieve the highest score possible. The longer you survive, the more challenging the game becomes!

## ✨ Features

- 🚗 Player-controlled car movement
- 🚙 Five different enemy car designs
- 🛣️ Two-lane traffic-dodging gameplay
- ❤️ Three-life health system
- 🏆 Score tracking system
- 📈 Three difficulty levels
- ⚡ Increasing enemy car speed
- 🌃 Neon-inspired night-city visuals
- 🎵 Background music and sound effects
- 📖 Dedicated instructions screen
- 🔄 Play Again and Main Menu options
- 🏁 Victory and Game Over screens

## 🕹️ Controls

| Key | Action |
|:---:|---|
| ⬅️ Left Arrow / A | Move Left |
| ➡️ Right Arrow / D | Move Right |

## 🏆 Scoring System

- Earn **10 points** for every enemy car successfully passed.
- Avoid collisions to protect your remaining lives.
- Keep playing and challenge yourself to achieve a higher score!

## 📊 Difficulty Levels

The game features three difficulty stages:

**Level 1 — Beginner**
- Score below 250
- Enemy speed: 550

**Level 2 — Intermediate**
- Score from 250 to 499
- Enemy speed: 700

**Level 3 — Advanced**
- Score of 500 and above
- Enemy speed: 850

*As you progress, enemy vehicles become faster and the challenge increases!*

## 🚀 Getting Started

Follow these steps to run the project:

1. Clone this repository:

   ```bash
   git clone https://github.com/thishen-dev/Traffic-Dodge.git
   ```

2. Install [Godot Engine](https://godotengine.org/).
3. Open Godot Engine.
4. Import the project by selecting the `project.godot` file.
5. Run the project and enjoy the game!
